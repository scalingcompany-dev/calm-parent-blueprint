# Calm Parent Blueprint™ — High-Converting Landing Page

A modern, responsive, high-converting webinar and workshop landing page built with pure semantic HTML, vanilla CSS, and JavaScript.

## 🌟 Features
- **Hero Section**: High-urgency announcement bar, workshop details (11 AM Sunday, Live Online, English), and social proof avatar stack.
- **Self-Assessment Matrix**: "This Programme is for you if..." pain-point check cards.
- **High-Value Bonuses**: Showcase cards for 3 practical toolkits (Worth ₹4,497).
- **Testimonials & Reviews**: Grid of student reviews with 5-star ratings.
- **Evergreen Countdown Timer**: 15-minute persistent urgency timer.
- **Interactive FAQ**: Accordion-style expandable questions and answers.
- **UTM Forwarding**: Preserves tracking parameters across checkout links.
- **Mobile Responsive**: Includes a sticky bottom CTA bar on scroll for mobile users.

## 🚀 Local Development
To run locally on port 3000:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment
- **Vercel**: Zero-configuration static deployment. Import repo on [vercel.com](https://vercel.com) or run `npx vercel --prod`.
- **GitHub Pages**: Supported out of the box from the `main` branch.
